# KAS — Khaled Auto Spares (خالد لقطع الغيار)

منصة وتطبيق متكامل لإدارة وبيع قطع غيار السيارات عبر الإنترنت (E-Commerce & ERP Auto Parts).

## 🚀 التقنيات المستخدمة (Tech Stack)
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- **Backend:** Node.js (Express), TypeScript, REST API.
- **Database:** PostgreSQL (Supabase / Railway) / SQLite fallback.
- **Infrastructure:** Docker, Nixpacks, Render / Railway ready.

## 📦 التثبيت والتشغيل (Getting Started)

### 1. تثبيت الحزم:
```bash
cd app
npm install
```

### 2. التشغيل في بيئة التطوير:
```bash
# تشغيل الخادم والواجهة معاً:
npm run dev:all

# أو تشغيل الواجهة فقط:
npm run dev
```

### 3. بناء المشروع للإنتاج:
```bash
npm run build
npm start
```
